# tfutils_json_deepmerge (Data Source)

Accepts a list of JSON strings and deep-merges them into a single JSON string. Later inputs take precedence over earlier ones for scalar values and objects. Arrays are replaced by default.

## Example Usage

```terraform
data "tfutils_json_deepmerge" "example" {
  input = [
    jsonencode({ region = "us-east-1", tags = { env = "dev", team = "platform" } }),
    jsonencode({ tags = { env = "prod", cost_center = "1234" } }),
  ]
}

output "merged" {
  value = data.tfutils_json_deepmerge.example.output
  # {
  #   "region": "us-east-1",
  #   "tags": {
  #     "cost_center": "1234",
  #     "env": "prod",
  #     "team": "platform"
  #   }
  # }
}
```

### Appending arrays instead of replacing them

```terraform
data "tfutils_json_deepmerge" "appended" {
  append_list = true
  input = [
    "{\"items\":[\"a\",\"b\"]}",
    "{\"items\":[\"c\",\"d\"]}",
  ]
}
# {"items":["a","b","c","d"]}
```

### Merging array elements one-by-one

```terraform
data "tfutils_json_deepmerge" "deep_list" {
  deep_copy_list = true
  input = [
    "{\"servers\":[{\"name\":\"web\",\"port\":80}]}",
    "{\"servers\":[{\"name\":\"web\",\"port\":443}]}",
  ]
}
# {"servers":[{"name":"web","port":443}]}
```

### Custom indentation

```terraform
data "tfutils_json_deepmerge" "indented" {
  indent = 4
  input  = ["{\"a\":1}", "{\"b\":2}"]
}
```

## Schema

### Required

- `input` (List of String) An ordered list of JSON strings to deep merge. Later entries take precedence.

### Optional

- `append_list` (Boolean) When true, arrays are appended rather than replaced by later inputs. Defaults to false.
- `deep_copy_list` (Boolean) When true, array elements are merged one-by-one: element N from each input is deep-merged together. Defaults to false.
- `indent` (Number) The number of spaces to use for indenting the output JSON. Defaults to 2.

### Read-Only

- `id` (String) Placeholder identifier attribute.
- `output` (String) The deep-merged JSON string.
