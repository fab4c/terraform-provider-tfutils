# tfutils_yaml_deepmerge (Data Source)

Accepts a list of YAML strings and deep-merges them into a single YAML string. Later inputs take precedence over earlier ones for scalar values and maps. Lists are replaced by default.

Behaves identically to the `deepmerge_yaml` data source in [terraform-provider-utils](https://github.com/cloudposse/terraform-provider-utils).

## Example Usage

```terraform
data "tfutils_yaml_deepmerge" "example" {
  input = [
    <<-YAML
      region: us-east-1
      tags:
        env: dev
        team: platform
    YAML
    ,
    <<-YAML
      tags:
        env: prod
        cost_center: "1234"
    YAML
  ]
}

output "merged" {
  value = data.tfutils_yaml_deepmerge.example.output
  # region: us-east-1
  # tags:
  #   env: prod
  #   team: platform
  #   cost_center: "1234"
}
```

### Appending lists instead of replacing them

```terraform
data "tfutils_yaml_deepmerge" "appended" {
  append_list = true
  input = [
    "items:\n  - a\n  - b\n",
    "items:\n  - c\n  - d\n",
  ]
}
# items: [a, b, c, d]
```

### Merging list elements one-by-one

```terraform
data "tfutils_yaml_deepmerge" "deep_list" {
  deep_copy_list = true
  input = [
    "servers:\n  - name: web\n    port: 80\n",
    "servers:\n  - name: web\n    port: 443\n",
  ]
}
# servers:
#   - name: web
#     port: 443
```

## Schema

### Required

- `input` (List of String) An ordered list of YAML strings to deep merge. Later entries take precedence.

### Optional

- `append_list` (Boolean) When true, lists are appended rather than replaced by later inputs. Defaults to false.
- `deep_copy_list` (Boolean) When true, list elements are merged one-by-one: element N from each input is deep-merged together. Defaults to false.

### Read-Only

- `id` (String) Placeholder identifier attribute.
- `output` (String) The deep-merged YAML string.
